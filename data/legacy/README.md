# data/legacy/

이 프로젝트의 `src/` 파이프라인이 만든 게 아니라, **이전에 만들었던 포트폴리오 산출물을
그대로 재활용**하는 데이터. `legacy_html/`의 대시보드 2종과 같은 성격이다.

- `용접_SPC_대시보드.xlsx` — 원본: `OneDrive\바탕 화면\포트폴리오\`. RSW(저항 스팟 용접)
  너겟 지름(mm) 측정치 기반 X-bar/R 관리도(600부분군, n=5, 총 3,000타점)와 Cp/Cpk 산출표.
  `app/pages/2_품질SPC.py`가 이 파일의 `Xbar_R_Data`, `Cpk_Table` 시트를 읽어 관리도·Cpk
  지표를 그린다. `data/raw/`와 달리 이 프로젝트 자체 실측 데이터는 아니므로 raw로 분류하지
  않았다.
