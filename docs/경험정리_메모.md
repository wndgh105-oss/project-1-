## STEP 13 배포 QA에서 발견한 것들 (2026-09-10)

### 1) 배포하니 설비예지보전 페이지가 깨질 뻔함 — 숨어있던 원본 데이터 의존성
- **무슨 일**: `data/raw/`(131MB)를 저장소에서 빼기로 했는데, 알고 보니 설비예지보전 페이지가
  실행 중에 `data/raw/azure_pdm`의 80MB telemetry CSV를 직접 읽고 있었음. 로컬에선 원본이
  있어서 문제가 안 드러났고, 배포 직전에야 발견.
- **어떻게 해결**: 그 계산(고장 파레토, 센서 전조 비교)을 미리 실행해서 결과만
  `data/interim/`에 저장해두는 스크립트(`precompute_page1.py`)를 새로 만들고, 페이지는
  그 결과만 읽도록 구조를 바꿈. 수정 전후 계산값이 100% 같은지 먼저 확인한 뒤 교체.
- **결과**: 배포에 필요한 데이터가 131MB → 약 116KB로 줄어 Git LFS 없이 그대로 배포 가능해짐.
- **한 줄 요약**: "로컬에서 잘 되던 게 배포하면 왜 깨지는가"를 몸으로 겪음 — 실행 환경이
  달라지면 로컬에선 안 보이던 암묵적 의존성이 드러난다는 걸 배포 QA로 직접 확인.

### 2) requirements.txt 최소화하다 패키지 하나 빠뜨림
- **무슨 일**: 배포용으로 requirements.txt를 최소화(불필요한 jupyter/scikit-learn 등 제외)
  하는 과정에서 `openpyxl`(엑셀 읽기 라이브러리)을 실수로 빠뜨림. 로컬 가상환경엔 이미
  깔려 있어서 로컬 테스트로는 못 잡았고, 실제 배포 후에야 ImportError로 드러남.
- **어떻게 해결**: 전체 소스코드의 import 문을 다시 처음부터 스캔해서 requirements.txt와
  하나하나 대조 확인. 빠진 패키지 추가 후 재배포.
- **한 줄 요약**: "로컬에서 돌아간다"는 "필요한 패키지가 다 명시돼 있다"를 보장하지 않는다
  — 가상환경이 이미 지저분해져 있으면(이것저것 깔아본 흔적) 이 차이가 안 보인다.

### 3) 그래프 텍스트가 막대와 겹쳐 보임
- **무슨 일**: What-if 시뮬레이터의 몬테카를로 분포 차트에서, "N회 모두 동일한 값" 안내
  문구를 플롯 정중앙에 고정해뒀는데, 막대 높이(반복 횟수)가 커지면 문구와 막대가 겹침.
- **어떻게 해결**: 문구 위치를 데이터 값(막대 높이)에 의존하지 않는 자리 — 플롯 영역
  바로 위 바깥쪽 — 로 고정해서, 어떤 반복 횟수가 와도 겹치지 않게 함.
- **한 줄 요약**: 시각 요소를 배치할 때 "지금 보이는 데이터 기준"이 아니라 "데이터가
  바뀌어도 안전한 기준"으로 앵커를 잡아야 한다는 걸 배움.
